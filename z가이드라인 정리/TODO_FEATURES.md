# 🚀 미구현 및 고도화 필요 기능 목록

요구사항 명세서와 현재 소스 코드를 면밀히 대조하여 확인된 상세 미구현 항목입니다.

## 1. 실시간 관제 시스템 (Monitoring)
- [ ] **기간/지역 필터**: 차트 상단의 '오늘/주간/월간' 및 지역별 필터 로직 (`ChartFilter.jsx` 활성화).
- [ ] **상세 통계 모달**: 차트 클릭 시 해당 데이터의 세부 수치와 추이를 보여주는 팝업.
- [ ] **위험 판독 [조회]**: 전화번호나 URL을 입력했을 때 DB 및 API를 통해 위험도를 판정하는 툴바/페이지.
- [ ] **위험 지역 맵 호버**: 지도 위 지역 호버 시 해당 지역의 구체적 통계 툴팁 표시.

## 2. 커뮤니티 (Community)
- [ ] **피해 현황 통계**: "이 수법에 00명 피해"와 같은 실시간 카운트 표시.
- [ ] **전문가 검증**: 보안 전문가 답변 시 전용 뱃지 부여 및 상단 고정 로직.
- [ ] **신고 및 추천**: 게시글/댓글 신고하기 버튼 및 '공감(추천)' 기능.
- [ ] **유사 사례 자동 연결**: 사용자가 작성한 글의 카테고리/내용을 분석하여 하단에 유사한 수법의 글 자동 추천.

## 3. 서비스 및 상품 (Service & Product)
- [ ] **상품 비교표**: 베이직, 패밀리, 프리미엄 요금제의 기능을 한눈에 비교하는 테이블.
- [ ] **Q&A 섹션**: 상품 구매 전 문의할 수 있는 전용 게시판 (현재 리뷰만 존재).
- [ ] **쿠폰 엔진**: 결제 시 쿠폰 코드를 입력하고 할인을 적용하는 백엔드/프론트엔드 로직.
- [ ] **검색 및 정렬**: 상품 리스트 페이지의 검색창 및 최신/인기/가격순 정렬 필터.
- [ ] **찜하기 연동**: 하트 클릭 시 유저별 찜 목록(DB)에 저장하는 기능 실연동.

## 4. 마이페이지 (MyPage)
- [ ] **리포트 고도화**: 진단 리포트 내 '개선 권장사항'의 실제 체크 기능 및 오답 유형 심층 분석 데이터 연동.
- [ ] **결제 프로세스 완성**: 토스페이먼츠 연동을 통한 실제 결제 완료 및 실패 처리 페이지 연결.
- [ ] **주문 사후 관리**: 주문 상세 보기 팝업 및 조건(배송 전 등)에 따른 '주문 취소' 로직 구현.

## 5. 가입 및 보안 (Auth)
- [ ] **역할 선택 가입**: 회원가입 시 일반/패밀리/프리미엄 등 서비스 역할을 선택하는 UI 추가.
- [ ] **인가 및 권한**: 관리자/운영자/일반 유저의 접근 권한 세부 분리 및 보안 보강.
- [ ] **자동 로그인**: '로그인 유지하기' 체크 시 리프레시 토큰을 활용한 자동 세션 복구.

## 6. 관리자/운영자 도구 (Management)
- [ ] **실시간 통계 API**: 대시보드의 가입자/방문자/이탈률 데이터를 실제 DB 통계 쿼리와 연동.
- [ ] **CS 라이브 챗**: 1:1 상담원 연결 UI의 실제 메시지 송수신 로직(WebSocket 등).
- [ ] **데이터 일괄 관리**: 블랙리스트 번호/URL의 CSV/Excel 대량 업로드 및 다운로드 UI.
- [ ] **배너/공지 제어**: 메인 배너의 노출 순서 변경(Drag & Drop) 및 기간 설정 기능.

## 7. AI 서비스
- [ ] **진단 히스토리 시각화**: 시간이 지남에 따라 변하는 내 취약도 점수 추이를 그래프로 표시.
- [ ] **맞춤형 콘텐츠 추천**: 진단 결과(취약점)에 딱 맞는 예방 교육 영상이나 뉴스 콘텐츠 자동 큐레이션.
- [ ] **시뮬레이터 고도화**: LLM 프롬프트를 강화하여 더 현실적인 사칭범 대화 유도 및 훈련 힌트 제공.
