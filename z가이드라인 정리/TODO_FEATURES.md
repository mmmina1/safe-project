# 🚀 전수 조사 기반 미구현 및 고도화 항목 (종합)

요구사항 명세서의 모든 항목을 소스 코드와 대조한 최종 분석 결과입니다.

## 1. 실시간 관제 시스템 (Monitoring)
- [ ] **URL 위험도 판정**: 메인 및 관제 페이지에 전화번호 조회는 있으나, URL을 입력해 결과를 받는 기능은 부재.
- [ ] **상세 통계 모달**: 차트나 지도의 지역/유형 클릭 시 세부 수치(유형별 건수, 평균 위험도)를 보여주는 팝업 연동.
- [ ] **데이터 필터**: 기간(오늘/주간/월간) 및 지역별 필터를 통한 데이터 재집계 로직 (`ChartFilter.jsx` 활성화).

## 2. 운영자 및 관리자 페이지 (Management)
- [ ] **1:1 실시간 상담**: `CsDashboardPage.jsx`는 메모/배정만 가능하며, 실제 실시간 메시지 송수신(WebSocket) UI와 로직이 없음.
- [ ] **CSV 대량 등록**: 블랙리스트 등의 데이터를 엑셀/CSV로 일괄 업로드하는 기능 및 UI 샘플 부재.
- [ ] **배너 노출 순서**: 관리자 페이지에서 배너의 노출 우선순위를 드래그 앤 드롭 등으로 조정하는 기능.
- [ ] **실시간 통계 연동**: 대시보드의 방문자/가입자 지표가 현재 정적 데이터이거나 500 에러 발생 상태 (DB 통계 쿼리 연동 필요).

## 3. 마이페이지 및 AI 서비스 (MyPage/AI)
- [ ] **RAG 출처 고도화**: 답변 생성 시 공신력 기관(경찰청 등)의 근거 출처를 명시하고 Vector DB(Chroma 등)와 연동하는 실질적 로직.
- [ ] **실행형 체크리스트**: 진단 결과에 따른 맞춤형 대응 수칙을 사용자가 하나씩 체크하며 관리할 수 있는 기능.
- [ ] **구독/멤버십 관리**: 토스페이먼츠 실제 결제 완료 후 유저의 역할(일반/패밀리/프리미엄)이 자동 전환되는 백엔드 연동.

## 4. 커뮤니티 및 상품 (Community/Product)
- [ ] **유사 사례 자동 매칭**: 현재 게시글과 비슷한 수법의 다른 글을 AI나 키워드로 분석해 하단에 자동으로 연결해주는 기능.
- [ ] **대댓글 UI 개선**: 로직은 존재하나 화면상에서 들여쓰기(Indentation) 등 계층 구조가 시각적으로 미흡.
- [ ] **상품 비교표**: 무료/유료 서비스의 차이를 한눈에 보여주는 테이블 레이아웃 부재.
- [ ] **수법별 피해 통계**: 커뮤니티나 메인에 "이 수법으로 인한 총 피해 건수" 등을 집계해 보여주는 위젯.

## 5. 로그인 및 기타 (Auth/Misc)
- [ ] **비밀번호 찾기 실연동**: UI는 있으나 실제 이메일 발송(SMTP) 및 임시 비밀번호 발급 백엔드 확인 필요.
- [ ] **가족/역할 가입**: 회원가입 시점에 서비스를 선택하거나 가족 계정을 묶는 초기 동선 부재.

## ✅ 구현 완료 (현 상태 유지 가능)
- **법적 문서**: 이용약관 및 개인정보처리방침의 상세 텍스트와 팝업 연동 완료.
- **기본 CRUD**: 게시글, 댓글, 상품 등록, 회원 검색 등 기초적인 관리 기능 작동 중.
- **AI 진단/챗봇**: 기본적인 설문형 진단 데이터와 챗봇 인터페이스 구성 완료.
- **지도 시각화**: Leaflet 기반의 지역별 마커 및 툴팁 표시 완료.
