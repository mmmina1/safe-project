# 🚀 미구현 기능 목록 (Unimplemented Features)

요구사항 명세서와 현재 소스 코드를 대조하여 확인된 미구현 및 고도화 필요 항목입니다.

## 1. 실시간 관제 시스템 (Monitoring)
- [ ] **기간/지역 필터**: 현재 UI가 비어 있으며, 기간별(주간/월간) 및 지역별 데이터 필터링 기능 필요.
- [ ] **상세 통계 모달**: 차트의 특정 요소 클릭 시 상세 로그 및 데이터를 보여주는 팝업창.
- [ ] **위험 판독 [조회] 서비스**: 
    - 메인 헤더 및 관제 페이지의 검색창 연동.
    - 입력된 번호/URL의 위험도를 판별하여 결과를 출력하는 기능 (백엔드 로직 포함).

## 2. 커뮤니티 (Community)
- [ ] **게시글 추천 및 공감**: "나도 받았어요", "도움돼요" 등 게시글 자체에 대한 추천 기능.
- [ ] **피해 인원 표시**: 수치화된 데이터 연동 (`00명이 이 사례를 확인했습니다` 등).
- [ ] **전문가 답변 뱃지**: 인증된 운영자나 전문가 댓글 시 강조 UI.
- [ ] **게시글 신고**: 불량 게시글 신고 접수 및 관리자 자동 연동.
- [ ] **유사 사례 자동 연결**: 현재 보고 있는 피해 사례와 수법이 비슷한 다른 글을 하단에 추천.

## 3. 서비스 및 상품 (Service & Product)
- [ ] **상품 비교표**: 케어 플랜 간의 혜택 차이를 한눈에 보여주는 테이블.
- [ ] **쿠폰 및 할인**: 결제 단계에서의 쿠폰 선택 및 할인 금액 적용 로직.
- [ ] **검색 및 정렬**: 상품명 검색, 가격순/인기순 정렬 필터 기능.
- [ ] **찜하기 (Wishlist)**: 관심 상품 등록 및 마이페이지 연동 (UI 버튼은 존재, 로직 미구현).

## 4. 마이페이지 (MyPage)
- [ ] **상세 취약점 리포트**: 진단 결과 중 오답 유형에 대한 세부적인 보안 가이드라인 출력.
- [ ] **주문 취소/환불**: 주문 내역에서 결제 취소를 수행하는 프론트/백엔드 로직 연동.

## 5. 관리자/운영자 도구 (Admin/Operator)
- [ ] **관리자 대시보드 데이터 실시간화**: 현재 정적(Static)으로 하드코딩된 차트 데이터를 DB 연동 데이터로 교체.
- [ ] **CSV 일괄 등록 UI**: 블랙리스트 관리 페이지에서 CSV 파일을 선택하여 대량 업로드하는 화면 추가.
